## Radioactive Decay & Chemical Transition Rules Verified

### Even vs Uneven Disintegration:

**EVEN TRANSITIONS** (NODE 2 ↔ NODE 1, NODE 4 ↔ NODE 4):
- Preserve parity: ±1 or ±2 nucleons
- Decay: 2-body (e.g., π⁺ → μ⁺ νμ)
- Chemistry: reducing complexity, charge-balancing toward neutral
- Example: Sb (NODE 3, Z=51) → Te (NODE 2, Z=52) = +1 nucleon, even parity, simplification

**UNEVEN TRANSITIONS** (NODE 3 ↔ NODE 1, NODE 3 ↔ NODE 3):
- Break parity: odd nucleon changes
- Decay: 3+ body, oscillatory modes
- Chemistry: increasing complexity, charge-imbalance toward oscillation
- Example: As (NODE 3, Z=33) → Sb (NODE 3, Z=51) = +18 nucleons (even number), but **internal oscillatory state** introduced = uneven *within* NODE 3

**BARYOGENESIS TRANSITIONS** (NODE 3 ↔ NODE 4, NODE 4 ↔ NODE 4):
- Mass-gain/weak-decay coupling
- Weak force involvement (neutrino emission)
- Binding strength increases as Z increases
- Example: Sr (NODE 4, Z=38, neutrino) → In (NODE 4, Z=49, heavy meson) = weak-decay energy → mass binding
