### 11. PRASEODYMIUM (Pr-59) / Roton at NODE 4

**RATIONALE:**

**Physics Foundation:**
- ✓ Roton: quasiparticle excitation in superfluid helium-4 (Landau phonon-roton spectrum)
- ✓ Dispersion relation: E(p) = ε + (p-p₀)²/2m*, gapped at roton minimum (~1.9 Å⁻¹ momentum)
- ✓ Roton gap: ~8.65 K in He-4 (meV scale), represents transition from phonon to particle-like excitation
- ✓ Weak decay: roton decays to phonons or creates vortex pairs in superfluid

**Radioactive Decay Type: BARYOGENESIS (Weak-Force Internal Deepening)**
- Cs(Z=55, down quark, fundamental) → Pr(Z=59, roton, quasiparticle): +4 protons
- Transition: FROM fundamental fermion → TO deep-binding quasiparticle excitation
- ✓ Characteristic: roton is gapped quasiparticle (meV scale), requires deep collective binding in superfluid
- ✓ NO ALTERNATIVE: NODE 4 REQUIRES deep-binding quasiparticles with gapped spectra; roton fits uniquely

**Enthalpy/Entropy:**
- ΔH = roton gap energy (~meV, bound quasiparticle state)
- ΔS ≈ 0 (coherent quasiparticle within superfluid order parameter, low dissipation)
- ✓ Fits NODE 4 pattern: deep binding, zero-entropy coherent state

**Oxidoreductive Transition:**
- Cs (ultra-reactive alkali, +1 valence) → Pr³⁺ (lanthanide, 4f³ valence, high redox flexibility)
- Transition: FROM single valence electron → TO triple f-orbital valence
- ✓ Mirrors roton: Cs simplicity (1 electron) → Pr complexity (3 f-electrons) reflects phonon → roton transition (simple acoustic → complex quasiparticle)

**Electronegativity Progression:**
- Cs: 0.79 (extreme donor)
- Pr: 1.13 (lanthanide, moderate)
- ✓ Trend: decrease in electronegativity reflects shift from reactive element to lanthanide inertness, mirrors superfluidity's isolation from external perturbations

**Dark Photon Routes:**
- Cs(NODE 4, down quark, QCD-confined) → Pr(NODE 4, roton, superfluid-confined) via **internal NODE 4 baryogenesis (no escape)**
- Energy locked: dark photon trapped in superfluid order parameter (analogous to QCD confinement)
- ✓ Matches roton physics: roton gap protected by superfluid coherence, dark photon cannot escape

**Route Logic:**
- In (NODE 4, charmonium) → Cs (NODE 4, down quark) → **Pr (NODE 4, roton)**
- ✓ Progression: composite charm binding → fundamental quark → superfluid quasiparticle excitation
- ✓ All NODE 4: deep binding, zero entropy, collective/fundamental coherence

- NODE 2 (even mesons): roton is NOT 2-body meson, but collective many-body excitation in superfluid

### 12. NEODYMIUM (Nd-60) / Majorana Fermion at NODE 2

- ✓ Majorana fermion: special fermion that is its own antiparticle (ψ = ψᶜ charge conjugate)

- Ba(Z=56, W-boson, charged weak mediator) → Nd(Z=60, Majorana fermion, neutral self-conjugate): +4 protons
- Transition: FROM charged 2-body mediator → TO neutral self-conjugate single-particle
- ✓ Characteristic: Majorana is "neutral even" = no charge but still particle (not antiparticle distinct)

- ✓ NO ALTERNATIVE: NODE 2 REQUIRES even-parity neutral carriers; Majorana is quintessential self-conjugate fermion

**Enthalpy/Entropy:**
- ΔH = Majorana gap (meV range in condensed matter, mass-dependent)
- ΔS > 0 (Majorana zero mode can occupy two conjugate states, entropy-relevant; fermionic parity fluctuation)
- ✓ Fits NODE 2 pattern: moderate binding, entropy-positive from fermionic degree of freedom

**Oxidoreductive Transition:**

- Transition: FROM paired-electron chemistry → TO unpaired f-electron chemistry
- ✓ Mirrors Majorana: Ba's paired-electron structure (each shell full) → Nd's unpaired f-electrons reflects particle-antiparticle distinction (Ba paired) → Majorana self-conjugate (no distinction needed)
