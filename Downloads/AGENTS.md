# Project Conventions

## Music Program — Tile Generation Logic

8D parameters (r, h, d, p, s, gamma, g, nu) each 0-1 scalar control sound synthesis. Genre emerges from combination — NOT genre-first.

Within the same slot, differentiation via:
- **nu↑** = fractal loops (0.3 = short loop, 0.9 = deep recursive)
- **h↑** = chord complexity (0.2 = power chords, 0.95 = microtonal clusters)
- **d↑** = scale darkness (0.1 = major, 0.9 = atonal)
- **r↑** = rhythm density
- **p** = predictability/form
- **s** = brightness/filter
- **gamma** = spatial/reverb
- **g** = structure/time signature

16 windows (t mod 16) shift peak dimension each window = no tile repeats.
8 base values × 16 peaks × 4 layers × JITTER ±15-30% × RANDOM(3AM) = thousands unique tiles/day.
Genre label is human-readable description of emergent sound, not selection input.
ENTP O M anchored, aggressively enlightening Koreans direction.

## Music Program — UI Rule: No Text Labels, Sound Only

NO text labels for anything music-related. No genre names, no parameter labels, no internal terminology, no color-coding exposed to user. User interacts purely by clicking tiles and listening. All communication through sound only, not text. Calibration is also done via tile selection (clicking and listening), not form-based selection.

## Element Ordering and Genre Mapping Logic

Order 118 elements by Layer 1 base blood type in toroidal cycle order: AB → A → O → B.

Map the 3 genres (RELEASE, STRESS GROWTH, EXTREME GROWTH) using Layer 3 logic (heterozygous ao, Rh+, blood type+1 shift O→A→B→AB→O).

- The profile label blood type (e.g. ENFP_M_O) is the Layer A base.
- EXTREME GROWTH uses base+1 blood type.
- Toroidal time slots: AB(0-3h), A(3-9h), O(9-15h), B(15-21h) correspond to RELEASE, STRESS GROWTH, present moment, EXTREME GROWTH respectively.
