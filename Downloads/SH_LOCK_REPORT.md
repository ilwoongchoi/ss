## Ridge region definition (frozen)
Ridge-band jobs are defined by `ridge_band_manifest.csv`, generated by `gen_ridge_band_manifest.py`:

- 25 `q0` values linearly spaced from `0.960` to `0.984`
- For each `q0`: `r = r_ridge(q0)` where `r_ridge(q0) = (769.82 - 686.01*q0) / 924.71` (P(high)=0.5 logistic ridge)
- 50 seeds each (`0..49`)
- Total jobs: `1250`

Validation performed:
- `ridgeband_Results/ridge_band/feature_cloud.csv` has `1250` rows.
- Key match on `(r,q0,seed)` vs `ridge_band_manifest.csv`: missing `0`, extra `0`.

## q_c lock (linear-mode sanity)
Detuned SH linear symbol (Fourier space) used by the sweep code:
- `L(k) = r - (q0^2 - |k|^2)^2`

k-axis convention (explicit in code):
- `kx = fftfreq(N, d=dx) * (2π)` and similarly for `ky`.

Therefore the linear growth is maximized at `|k| = q0`, so:
- `q_c = q0`

Canonical registry choice:
- Lock `q_c` as `median(q0)` over ridge-band manifest (same 1250 ridge jobs).

Results:
- `q_c` (median q0) = `0.972`
- `q0` Q1 = `0.966`
- `q0` Q3 = `0.978`
- `q0` IQR = `0.012`

Registry action:
- Set `sh.q_c.value = 0.972`
- Stored tolerance as q0 IQR.
