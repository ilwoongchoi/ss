# how do you search for text in content on everything software?

To search for text within the content of files using **Everything** (by voidtools), you can use specific search functions or the built-in Advanced Search menu. Note that since Everything primarily indexes filenames, content searching is slower as it must scan the actual data inside the files.

### 1. Using Search Functions (Recommended)

You can type a prefix directly into the search bar followed by your search term. The most common functions are:

- **`content:text`** – Searches for "text" within the file content .
- **`ansicontent:text`** – Searches specifically for ANSI-encoded text.
- **`utf8content:text`** – Searches specifically for UTF-8 encoded text.
- **`utf16content:text`** – Searches specifically for UTF-16 encoded text.

**Example:** To find all `.txt` files containing the word "Einstein", you would type:
`*.txt content:Einstein`

### 2. Using the Advanced Search Menu

If you prefer a graphical interface, you can access the content search through the menu:

1. Go to **Search** > **Advanced Search...**
2. Locate the field labeled **A word or phrase in the file** .
3. Type your text there and click **OK**.

### 3. Performance Considerations

Because Everything does not index file content by default, these searches can be slow, especially on large hard drives. To speed this up:

- **Filter by file type first**: Add an extension or folder filter before the content command (e.g., `D:\Documents\ *.pdf content:"red dwarf"`) .
- **Everything 1.5 (Alpha)**: If you are using the 1.5 Alpha version, you can enable **Content Indexing** in `Options > Index > Content`. This allows for near-instant content searching but significantly increases the size of the database file on your disk .


### 4. Search Syntax Tips

- **Quotes**: Use double quotes if your search term contains spaces: `content:"cosmic ray"` .
- **Case Sensitivity**: Add `case:` to make the content search case-sensitive: `case:content:GABA` .
