### Core Framework Components

#### State Model Implementation
- **Canonical State**: `S_e = (hit_graph, signal_field, momentum_proxy, environment_state, scattering_state, mediator_state, barrier_state, closure_state, origin_hypothesis)`
- **Observable Classes**: Direct, Reconstructed, Latent, Ambiguity
- **Update Rules**: Observation, Reconstruction, Mediator Insertion, Barrier Classification, Closure Assessment

#### Closure Grammar Translation
- **Node**: Hit/interaction evidence, localized charge evidence, event vertex
- **Seam**: Local trajectory continuity between adjacent hits
- **Bridge**: Inferred continuity across a gap with statistical support
- **Mediator**: Sub-threshold signal, scattering vertex, correlated side-channel
- **Barrier**: True detector dead zone, irrecoverable discontinuity
- **Projection Trap**: Zero-suppression gap, threshold loss, reconstruction omission
- **Hidden Lift**: Continuity revealed only in transformed domains

#### Implementation Ladder
- **Level 1**: Detector-scale traceability (currently implementable)
- **Level 2**: Many-body/material regime (partially implementable)
- **Level 3**: Plasma/astrophysical regime (statistically implementable)
- **Level 4**: Cosmological extension (architecture only)

#### Gap Classification System
- **Six Primary Classes**: true_barrier, projection_trap, hidden_lift, relay_available, mediator_required, irrecoverable_gap
- **Decision Rules**: Explicit algorithms with confidence scoring
- **Falsification Paths**: Clear validation and rejection criteria

#### Pilot Experiment
- **Three Falsifiable Predictions**: Sub-threshold signals, scattering vertices, cross-detector continuity
- **Smallest Experiment**: Sub-threshold signal search in tracking gaps
- **Success Criteria**: >80% mediator recovery, <5% false positive rate

#### Cosmological Extension
