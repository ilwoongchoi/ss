# Geology/Seismology Domain Transfer: Closure Grammar → Fault Continuity

## Source Method (Locked Closure Theorem)

The closure grammar provides a reproducible framework for connectivity reconstruction under sparse observation:
- **Internal closure**: Hard bound at N components within original observation universe
- **Extended closure**: N→1 reduction via minimal external mediator
- **Key distinction**: True barriers vs. projection traps vs. hidden lifts

## Domain Selection: Segmented Fault Traces with Missing Intervals

**Rationale**: Cleanest falsifiable test with minimal moving parts
- Observable surface expression (fault scarps, lineaments)
- Clear gaps (erosion, burial, vegetation cover)
- Subsurface structure verifiable (seismic profiles, trenching)
- Matched controls available (non-faulted terrain with similar cover)

## Phase Mapping

### Phase 1: Internal Closure (Standard Geological Mapping)

```
Universe: Surface fault traces from aerial photo / satellite / field mapping
Nodes: Segment endpoints (visible fault termini)
Bridges: Lineament connections based on alignment
Relay: Segment chains with consistent strike/slip sense

Hard bound: 2+ components
- Component A: Main fault cluster (connected segments)
- Component B: Isolated segments (projection trap gaps)
```

**Barrier**: True structural break (A↔C equivalent) — cross-cutting fault of different age/kinematics.

### Phase 2: Extended Closure (Mediator-Assisted)

```
Universe expansion: Add subsurface mediators
- Seismic reflection profiles
- Microseismicity clusters
- Geomorphic lineaments
- Gravity/magnetic anomalies

External mediator: Minimal subsurface structure enabling segment linkage
Relay: segment → seismic corridor → segment
```
