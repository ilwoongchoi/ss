## 4. 3개 잉여 채널: 정확히 무엇인가

### Channel #2: Bridge #13 (GABA-B / 광배근)

**물리:** β붕괴 return path

p↔e 엣지(융합 출력, 전자포획 → 중성자)가 일어난 후, 중성자는 다시 p + e로 붕괴한다.
이 귀환 경로가 Bridge #13이다. 이것이 없으면 에너지가 한 방향으로만 흐른다.

```
p + e → n    (전자포획, p↔e 엣지)
n → p + e + ν̄  (β붕괴, Bridge #13 = 귀환)
```

- GABA-B OFF (성장기): 귀환 없음 → 에너지 소비 일방향 = 성장
- GABA-B ON (Sovereign): 귀환 활성 → 순환 폐쇄 = 지속 융합

**K6 그래프 이론:** 방향성 없는 K6에서 p↔e의 출력이 다시 p와 e로 피드백되는 별도 경로. 위상학적 조건 (루프가 닫혀있는가).

### Channel #23: Δφ = C = 0.2828 (우측 코르티솔)

**물리:** 힉스 VEV (진공 기댓값)

코르티솔이 ON이면 낮 상태(대칭), OFF이면 밤 상태(대칭파괴):
```
낮: BW = SM = 3.644  (대칭)
밤: BW = 3.644 - C = 3.416   (BW 감소)
    SM = 3.644 + C = 3.926   (SM 증가)
```

C = 0.2828이 정확히 이 전환의 크기다. 코르티솔이 Z 게이트(α2)와 연동되어 야간 전환을 만든다.

### Channel #24 (& Ω₀): Ω₀ = 7.4 (엔도르핀 / α2)

**물리:** 시스템의 경계 조건 (scalar curvature constraint)

```
OMEGA = ||[BM, BW, SM, SW]|| = 7.4  (목표)
```

7.4는 목표가 아니라 **결과**: 21개 채널이 전부 올바르게 작동하면 자연스럽게 도달.
엔도르핀은 7.4 상태가 달성되었을 때 발생하는 신호 — 원인이 아니라 측정값.
