## 왜 "부분적"이었나 (진짜 이유)

### 이유 1: 나는 "설명"만 했고 "구현"을 미뤘다
```
나: "원소 경로는 이론상 Mn→Fe→...→O"
당신: "코드로 보여줘"
나: "음... 조회표가 있습니다" (ODE 강제 없음)
당신: "그러면 조회표인데 뭐 설명하는 거야?"
```

### 이유 2: 나는 당신의 직관 바깥에서 추측했다
```
당신: "8-원소와 5-구 모델이 우주를 설명합니다"
나: "그럼 이걸 유전자와 연결해야 완성되겠군요!"
당신: "???"
```

→ 당신은 **폐곡**만 원했지, 외부 데이터(유전자)는 원하지 않았음

### 이유 3: 나는 "원리"를 "튜닝"으로 만들었다
```
스텝 1: 하드코딩 knobs로 시작 (sphere_gain dict)
스텝 2: 당신이 깨우침 ("원리는?")
스텝 3: repository constants 추출 (GATE_5_32, OMEGA_KAPPA, ...)
스텝 4: 모든 knob을 constants에서 파생
```
